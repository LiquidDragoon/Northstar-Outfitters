# Definition of Done

A feature is complete when:

- requirements are mapped to acceptance criteria,
- domain rules are implemented and tested,
- integration behavior is tested where applicable,
- error handling is defined,
- security implications are reviewed,
- logs/metrics are adequate for operations,
- API documentation is updated when applicable,
- database migrations are version-controlled,
- static analysis passes,
- security scanning passes,
- code review is approved,
- CI is green,
- documentation is updated,
- deployment/rollback implications are known.
